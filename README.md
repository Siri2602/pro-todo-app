# pro-todo-app
"A dynamic To-Do app with search,filter and local storage"

This is a simple to-do list project made using HTML, CSS and JavaScript.  
I created this project to practice frontend development and improve my JavaScript skills.

Users can:
- Add tasks
- Complete tasks
- Delete tasks
- Search and filter tasks

The design is simple, clean and easy to use.
